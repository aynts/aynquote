# Aye Yeik Nyo Co., Ltd. - Quotation & Invoice Management System

A single-page application (SPA) for generating, editing, and managing professional solar system Quotations and Invoices for **Aye Yeik Nyo Co., Ltd.**

## Features
- **Executive Letterhead Layout**: 3-Column header with company credentials, logo, and document metadata.
- **Dynamic Product & Service Table**: Drag & drop row reordering, automatic numbering, section summaries, and live totals.
- **Microsoft OneDrive & Local Storage Integration**: Uses the File System Access API to automatically save and organize documents in Quotations/YYYY/MM/ and Invoices/YYYY/MM/.
- **Single-Page A4 PDF Export**: jsPDF + AutoTable engine for PDF generation with custom warranty terms and signatures.
- **Document History & Recovery**: Live draft caching in localStorage and local directory indexing.
